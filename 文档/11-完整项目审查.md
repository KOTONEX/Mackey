# 完整项目审查与修复记录

本轮以 `rust` 分支提交 `d6d9c5a` 为基线，审查 Rust 业务与 CLI、TypeScript 扩展和真实契约、构建脚本、薄启动壳、测试、归档、GitHub 工作流、规范与文档。修复在开发分支验收，未安装到宿主，也未修改正在运行的键盘服务或 GNOME 设置。

## 已修复问题

| 问题 | 修复与回归证据 |
| --- | --- |
| 不完整安装停用/卸载时，缺失单元导致整个流程失败 | 逐个检查 LoadState，跳过不存在的单元；先停引擎后停焦点桥；隔离测试覆盖只有一个单元及重复卸载 |
| 体检输出问题但退出状态仍是成功 | 待处理项非空返回失败；测试保证 `体检` 不启用服务 |
| 合法自动布局在生成时被拒绝 | 生成时识别布局，不改写用户文件；初始化仍保存当次识别值，保留既有语义 |
| 微软修饰映射没有跟随设备过滤，非法过滤值被静默丢弃 | 修饰映射与业务映射均使用设备范围；读取配置严格验证过滤类型 |
| 备份含非法项目时可能先修改部分键，再将错误值还原为空数组 | 在还原、卸载和合并备份前完整校验；回归验证失败前没有外部操作；保留 GVariant 中的空字符串 |
| 多项 GNOME 迁移中途失败留下半完成状态 | 失败后逆序回滚本次尝试的原值，保留最早备份；回归区分本次原值和历史备份 |
| 自定义套接字与服务硬编码地址不同，Environment 美元转义与 ExecStart 混用 | 两个服务使用实际路径，环境值与命令参数分别转义；覆盖美元、百分号、引号和空格 |
| 焦点查询失败无限沿用缓存，错误 JSON 字段被当作空焦点 | 清缓存并标记失效，焦点桥退出；引擎 BindsTo/After 绑定焦点桥；单元测试覆盖错误字段与缓存失效，保留合法无窗口空焦点 |
| 源码入口优先执行旧二进制，默认构建目标影响测试定位 | 薄壳始终调用 Cargo；测试显式编译宿主并从 Cargo 产物目录定位；薄壳契约核验参数 |
| 编译器同路径升级或生成失败可能遗留资源 | 注册原生编译器文件为重建依赖，生成前清理输出目录；继续严格 TS 与真实 GJS 验证 |
| 引擎 ZIP 可接受错误 ELF 位数、字节序或版本标记 | 下载只接受支持架构的 ELF64、小端和有效版本头；测试覆盖非法头 |
| 双架构包与源码/扩展缺少来源一致性校验 | 包内写发行信息，核验版本、架构、提交与二进制/扩展摘要；全扫描拒绝特殊、重复或越界条目，提取前校验；汇总拒绝提交不一致 |
| 重跑发布可覆盖已公开附件 | 工作流拒绝修改公开 Release，只允许草稿重试；修复应另发版本 |
| 虚拟键盘极大延迟参数可导致 Duration panic | 设备创建前采用可失败转换，覆盖非数、负数、无限和溢出值 |
| 项目规范重复、入口过长，PR 模板残留已删除命令 | 按项目规范技能整理统一正文、简短 AGENTS 入口及真实开发/验收命令，保持业务和 AGPL 边界 |

## 本地验证

- `cargo 检查`：格式、Clippy、Rust/严格 TypeScript、ShellCheck、JSON 全部通过。
- 42 项 Rust 测试：19 项库测试、5 项命令行、16 项隔离安装卸载、2 项虚拟键盘参数/ABI；隔离总线和命令桩避免操作真实用户会话。
- 115 条生成映射及迁移结果与既有基准一致；修复没有改写基准来掩盖差异。
- 13 项真实 GJS/D-Bus 契约断言通过：实际扩展代码、私有总线、Rust 进程往返、空焦点与撤销导出。
- 本机发行包解压后版本、许可证、发行信息、ELF 和独立生成差分通过。交付还需从已提交的干净副本打包并运行远程双架构 CI、发布附件汇总；不把本机成功算作远程成功，最终状态以相应提交的执行记录为准。
- 工作流 actionlint、编译器准备脚本 ShellCheck、本地 Markdown 链接及 Git 空白检查通过。

## 范围和限制

本轮没有重新执行设备端到端注入：本机全局引擎正在工作，不为审查停止用户服务。既往真实五例设备验证见 [本机端到端测试报告](10-本机端到端测试报告.md)，不当作本轮结果。新焦点失效行为通过缓存/JSON 回归及真实扩展契约验证，未实际断开用户总线或测试真实 systemd 故障恢复。

离线基准覆盖生成结果，不意味着逐条按下 115 组键；ARM64 由原生 CI 验证，不宣称本机设备测试。应用版本暂仍为 2.3.1，开发分支修复不替换已有标签或公开附件。`main` 未改动，宿主仍运行此前安装版本。

统一项目边界见 [项目规范](项目规范.md)。
