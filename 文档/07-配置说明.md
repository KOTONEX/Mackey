# 配置说明

返回 [文档索引](README.md)。安装和应用配置见 [使用指南](使用指南.md)。

## 用户配置

默认路径为 `~/.config/mackey/config.json`，支持 `XDG_CONFIG_HOME` 覆盖；文件必须是 JSON 对象。
以下是可直接使用的 JSON 示例：

```json
{
  "修饰键布局": "苹果",
  "device": {"only": [], "not": []},
  "keypress_delay_ms": 0,
  "引擎": ""
}
```

| 字段 | 含义 |
| --- | --- |
| `修饰键布局` | `苹果`、`微软` 或 `自动`，具体行为见下文 |
| `device.only` / `device.not` | xremap 设备过滤；字符串或字符串数组，空范围不限定键盘 |
| `keypress_delay_ms` | xremap 按键延迟；个别应用不敏感时可尝试 20 毫秒 |
| `引擎` | 自定义 xremap 路径，留空时查找已安装引擎等候选位置 |

`安装` 会保留已有用户字段并补齐缺省值。说明字段 `_修饰键布局_说明`、`_设备_说明`、
`_按键延迟_说明` 与 `_引擎_说明` 供阅读，不是映射规则。
修改后执行 `mackey 应用`，仅执行 `生成` 不会重启正在使用旧配置的引擎。

## 键盘布局

- `苹果`：Super 作为 ⌘，不交换物理 Alt/Win。
- `微软`：交换 Alt/Super，让空格旁的 Alt 位置成为 ⌘；设备过滤同样作用于该修饰映射。
- `自动`：生成时读取当前键盘信息选择布局，不改写输入文件。
  `初始化` 和 `安装` 会将自动值保存为当次识别结果；不是持续热插拔切换服务。

可先运行 `mackey 识别键盘` 查看候选设备及建议。识别读取 `/proc/bus/input/devices`，
优先外接候选，再按厂商和名称判断 Apple 特征；它不读取物理 Mac/Win 拨档状态，
也不会由 `device.only` 自动确定布局。判断不符合预期时，显式设置 `苹果` 或 `微软`。

## 三个配置档与自定义清单

配置档名称为 `终端`、`文件管理器`、`通用`，应用匹配与具体映射以
[配置/行为清单.json](../配置/行为清单.json) 为准。

| 清单部分 | 用途 |
| --- | --- |
| `应用档` | 终端与文件管理器应用的匹配表达式 |
| `条目` | 显式行为、归属、触发键、目标组合及迁移引用 |
| `迁移规则` | GNOME 键名、触发条件和迁移目标 |
| `吞控制组合.例外应用` | 为带内嵌终端等应用保留 Ctrl+C 和其它原生组合 |
| `吞终端组合` | 终端中物理 Ctrl+Shift+C/V 的点状吞键规则 |
| `泛化兜底.排除触发键` | 从泛化映射中排除组合，例如 `Super-u` |

在源码修改清单后，通过 [贡献指南](../CONTRIBUTING.md#修改行为与生成文档) 重新生成文档、检查并部署。
也可用 `mackey 生成 --行为清单 <文件>` 指定外部清单；该参数属于生成命令，
普通 `mackey 应用` 仍使用二进制内嵌清单，不把一次生成误当成永久切换清单。

清单的自有值采用中文：策略为 `转换`、`自动`、`放行`、`跳过`；
状态为 `需映射`、`近似`、`需迁移`、`原生等价`、`可选`、`无法模拟`；
归属为 `苹果风格`、`系统默认`；泛化类别为 `字母`、`上档字母`、`上档数字`。
行为、迁移标识及引用和生成规则的自由显示名称也使用中文。

## 外部字段与固定路径

xremap 的 `device`、`keymap`、`remap`、`name`、`application`、按键代码及标准布尔值保持协议原名。
GNOME 模式与键名、D-Bus 方法、应用标识、引擎特性 `gnome`/`full` 和第三方原始错误同样保留。
自有引擎安装记录用 `摘要` 保存 SHA-256；它是状态数据，不是用户配置字段。

部署文件 `config.json`、`xremap.json`、`relocations.json`、`backup/gsettings.json` 和 `bin/mackey`
保留既定位置。完整 XDG 落点见 [架构与边界](02-架构与边界.md#home-与-xdg)。
命令帮助保留标准 `--help`/`-h` 与 `--version`/`-V`。

## 旧版重装

旧自有命令、字段和布局值不提供兼容别名或自动转换。
若程序提示旧配置不受支持，请先另存需要的个人配置，再使用旧版本自身的卸载命令，
还原 GNOME 键位并清除旧配置；然后使用新版安装。
Python 版需在旧仓库执行 `./uninstall.sh --yes`，新版源码使用 `cargo 运行 安装`，
发行包使用 `./mackey 安装`。不要把整份旧配置覆盖回来。

旧字段 `modifier_layout`、`engine` 及旧布局值 `apple`、`pc-swap`、`auto` 等会被拒绝。
重新安装后的加载和启用步骤见 [使用指南](使用指南.md#安装与首次启用)。
