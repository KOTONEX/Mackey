# 架构与边界

返回 [文档索引](README.md)。安装和故障操作见 [使用指南](使用指南.md)。

## 按键与焦点数据流

```text
物理键盘 → evdev → xremap → uinput → GNOME / 应用
                    │
                    └→ 用户 Unix socket → Rust 焦点桥 → D-Bus → GNOME 扩展
```

xremap 负责实际读取、重映射和合成按键。Rust 焦点桥从扩展取得焦点窗口信息，
以 xremap 约定的 Unix socket JSON 行协议响应查询。扩展只查询焦点，不监听键盘或注入事件。

[行为清单](../配置/行为清单.json) 是映射、冲突迁移及例外的唯一事实源。
生成器结合用户配置、GNOME 当前键位和清单，输出 `xremap.json`、`relocations.json`
及 [行为文档](03-行为清单.md)。配置档为终端、文件管理器、通用；用户字段见 [配置说明](07-配置说明.md)。

## 行为边界

- 不全局交换 Ctrl/Super。微软布局只交换 Alt/Super 的物理位置，且遵循设备过滤。
- 终端使用专门映射；吞控制组合独立生成，并排除终端及 `例外应用` 中的 IDE。
  泛化兜底不作用于终端，还会避开 GNOME 已占用组合。
- GNOME 冲突只迁移实际需要的键，先保存原值。迁移失败逆序回滚本次尝试，
  保留最早备份；还原前完整校验备份，不能把无效数据写成空绑定。
- 应用身份基于焦点窗口，无法区分同一 IDE 窗口内的编辑区与内嵌终端。
  对未列入的应用，应检查实际标识后调整清单，不把所有应用统一套用终端规则。

## 焦点保护与服务恢复

`mackey-focusd.service` 使用 `Type=notify`。验证焦点来源、绑定 socket、设置 0600 权限
并准备接受请求后上报 `READY=1`，再以非阻塞的 `ExecStartPost` 启动引擎。
焦点桥失败按两秒间隔重试，避免登录时 GNOME 扩展尚未就绪导致永久失效。

`mackey-engine.service` 通过 `Requires`、`BindsTo` 和 `After` 依赖焦点桥。
来源查询失败时桥接清除缓存并退出，引擎随之停用；桥接恢复就绪后重新拉起引擎。
不把过期焦点无限当作有效结果，不以依赖互拉绕过重试间隔。

`mackey 停用` 在同一事务中停用两项服务，主动停用后不会由恢复流程重新启用。
安装不自动启动；`启用` 和 `应用` 会验证焦点来源、当前 input 组权限和 socket。
登录时序与隔离恢复回归的历史证据见 [2.4.1 修复报告](历史/13-2.4.1登录恢复修复.md)。

## HOME 与 XDG

| 内容 | 默认位置或覆盖变量 |
| --- | --- |
| 命令入口 | `${XDG_BIN_HOME:-~/.local/bin}/mackey`，指向数据目录中的独立二进制 |
| 用户配置与生成配置 | `${XDG_CONFIG_HOME:-~/.config}/mackey/` |
| 原始 GNOME 键位备份 | 配置目录中的 `backup/gsettings.json` |
| Mackey 与 xremap 二进制 | `${XDG_DATA_HOME:-~/.local/share}/mackey/bin/` |
| 下载中间产物 | `${XDG_CACHE_HOME:-~/.cache}/mackey/` |
| 引擎安装记录 | `${XDG_STATE_HOME:-~/.local/state}/mackey/engine.json` |
| GNOME 扩展 | `${XDG_DATA_HOME:-~/.local/share}/gnome-shell/extensions/mackey-focus@kotonex/` |
| 用户服务单元 | `${XDG_CONFIG_HOME:-~/.config}/systemd/user/` |
| 焦点 socket | `${XDG_RUNTIME_DIR:-/run/user/$UID}/mackey-focus.sock` |

持久写入和测试临时目录均限制在 HOME，路径检查逐段解析软链接和 `..`。
`/run/user/$UID/mackey-focus.sock` 是唯一 HOME 外 IPC 例外，权限为 0600；
其他自定义 socket 位置必须在 HOME 下。持久 XDG 目录指向 HOME 外时会拒绝写入。
写文件采用同目录临时文件、权限设置、同步和原子替换；不宣称跨文件及外部服务整体原子。

| `源码/程序/` | 命令解析与中文帮助 |
