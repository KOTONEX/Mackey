# 中文接口与重新安装

自有命令、参数、配置字段、源码 API 和目录使用中文，不接受旧命令别名、旧配置字段或旧布局值。

## 从 Python 版重新安装

先在**旧版本的仓库**执行卸载，让旧版本还原 GNOME 键位并清除配置，再使用新版安装。

```bash
./uninstall.sh --yes
```

然后在新版源码目录执行：

```bash
cargo build --locked --release
./安装.sh
# 重新登录，加载 GNOME 扩展并取得 input 组权限后：
mackey 体检
mackey 应用
```

也可解压二进制发行包，运行 `./mackey 安装`，无需 Rust 或源码仓库。
请先另存自己需要的配置内容；卸载后按新字段重新配置，不复制整份旧配置。

布局仅接受 `苹果`、`微软`、`自动`。`微软` 交换物理 Alt/Win，让空格旁的键成为 ⌘。
旧英文键 `modifier_layout`、`engine` 及旧布局值 `apple`、`pc-swap`、`auto`
会触发错误，提示卸载重装；程序不自动转换或创建升级备份。

## 外部协议

xremap 的配置字段与按键名、D-Bus 方法与 JSON 载荷、GNOME 必需的扩展文件名、systemd
服务名、XDG 位置和 Cargo 标准文件名继续遵循对应外部工具的要求。
`config.json`、`xremap.json`、`relocations.json` 等持久文件位置不影响“先卸载再安装”的要求。
