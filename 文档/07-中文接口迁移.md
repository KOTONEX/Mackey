# 中文接口迁移

2.0.0 将自有命令、参数、配置键、Rust API、源码与测试目录统一为简体中文，规范参照 AdwCode。
命令不保留英文别名，例如 `mackey 获取引擎`、`mackey 初始化`、`mackey 安装 --不下载`、
`mackey 应用 --确认执行`、`mackey 卸载 --预演`；以 `mackey --help` 查看完整接口。

开发统一执行 `cargo run --quiet -- 检查`。仅固定 Rust Edition 2024，不提交工具链版本文件，
不设置 rust-version；应用版本以 Cargo.toml 为唯一事实源，Cargo.lock 锁定应用依赖。
变更日志由 Git 提交标题和版本标签生成到 builddir/，不手工维护根目录 CHANGELOG.md。

## 配置升级

旧用户配置仍位于 `${XDG_CONFIG_HOME:-~/.config}/mackey/config.json`。
`初始化` 和 `安装` 将 `modifier_layout`、`engine` 及对应说明字段改为
`修饰键布局`、`引擎`；布局值 `apple`、`pc-swap`、`auto` 分别升级为 `苹果`、`电脑换位`、`自动`。
中文键优先，设备过滤及其他已有字段保留。首次改写前保存原文为
`config.json.汉化前备份`（0600），再次运行不会覆盖此备份。
生成配置时可读取旧字段，但不会修改输入配置。

旧源码行为清单需要按照 `配置/行为清单.json` 的中文字段迁移，不能直接作为 2.0 清单输入。
例如 `吞控制键.例外应用` 取代旧清单的 `swallow_ctrl.except_apps`。

## 明确保留的外部接口与升级路径

- Cargo、Git、GitHub、GNOME/GJS、XDG、systemd 的标准名称与文件保留原名。
- xremap 的 `keymap`、`modmap`、`application.only/not`、`device`、键名、协议字段
  `wm_class` 和 `title` 保持上游格式；已有生成规则名称保留以便差分验证和日志识别。
- GNOME 扩展 UUID `mackey-focus@kotonex`、GJS 的 `extension.js`/`metadata.json`，
  D-Bus 方法及第三方后端标识 `k0kubun`/`focused-window` 保留原名。
- 已部署的 `config.json`、`xremap.json`、`relocations.json`、`backup/gsettings.json`、
  `bin/mackey`、`bin/xremap`、`engine.json`、`data/docs/03-行为清单.md`，以及
  `mackey-{focusd,engine}.service` 和 `mackey-focus.sock` 保留原路径，避免丢失配置和还原数据。
- `.git`、`.github`、`.vscode`、`LICENSES`、target、builddir 和工具缓存保留约定名称。
  许可证原文及第三方名称保留原文；Mackey 继续采用 AGPL-3.0-or-later。

源码目录改名后应重新编译并安装。升级操作不会自动启用引擎；焦点来源通过验证后再执行 `应用`。
