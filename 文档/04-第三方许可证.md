# 第三方许可证与引用说明

本仓库整体以 **AGPL-3.0-or-later** 发布（全文见 [LICENSE](../LICENSE)）。本文登记与
本项目相关的第三方项目及其许可证，以及必要的兼容性说明。

## 1. 直接引用或兼容实现

### 1.1 xremap（键位引擎）— MIT

- 上游：<https://github.com/xremap/xremap>（License: MIT）
- 关系：Mackey 以 xremap 作为按键引擎。`mackey 获取引擎` / `cargo 运行 获取引擎`
  按指令集架构下载官方发布版本（固定 `gnome` 特性）的独立二进制，存放在
  `${XDG_DATA_HOME:-~/.local/share}/mackey/bin/xremap`。
- 边界：不修改其源码、不把二进制纳入本仓库；运行时按 MIT 许可使用。

### 1.2 xremap-gnome（D-Bus 契约参考）— 上游未附 LICENSE，源码文件头标注 GPLv2+

- 上游：<https://github.com/xremap/xremap-gnome>
- 关系：本仓库的 GNOME 扩展 `扩展/mackey-focus@kotonex` 是对其公开 D-Bus 接口
  （`com.k0kubun.Xremap.ActiveWindow`）的**独立实现**：只读查询焦点窗口，不注入按键、
  不监听键盘；目的是在 GNOME 45+ 上修复 xremap 的 application 匹配。
- 许可说明：上游仓库没有 LICENSE 文件，`extension.js` 文件头标注
  `Copyright (C) 2022 Takashi Kokubun` / `Licence: GPLv2+`（即 GPL-2.0-or-later）。
  GPL-2.0-or-later 可按其 「or later」 升级为 GPL-3.0，而 GPLv3 与 AGPLv3 可依
  AGPLv3 第 13 节组合，因此本项目整体采用 AGPL-3.0-or-later 与之兼容。

### 1.3 GNOME Shell — GPL-2.0-or-later

- 关系：扩展的运行环境。本仓库只调用其公开的扩展 JS API 与 D-Bus 接口，
  不复制 GNOME Shell 源码。

### 1.4 @girs 类型声明快照（随仓库分发）— MIT

- 上游：<https://github.com/gjsify/gnome-shell>、<https://github.com/gjsify/types>
  （由 ts-for-gir 生成）。
- 关系：扩展、真实 GJS 契约与基类桩的 TypeScript 类型主要来自官方 `@girs` 声明。
  项目不引入 Node/npm，因此把入口实际引用的 32 个 `.d.ts`（约 4.6 MB）作为快照收录在
  `类型声明/girs/`，`tsconfig.json` 用 `paths` 把 `@girs/*` 映射到该目录。
  收录的包为 `@girs/gnome-shell` 51.0.1 与 `@girs/gjs`、`@girs/gio-2.0`、
  `@girs/glib-2.0`、`@girs/gobject-2.0`、`@girs/gmodule-2.0`、`@girs/cairo-1.0` 5.6.0；
  tarball、`sha512` 完整性摘要与上游地址见 `类型声明/girs/来源.json`。
- 许可：各包 `package.json` 声明 MIT；`@girs/gnome-shell` 的 LICENSE 标注
  `Copyright (c) 2023-2024 Pascal Garber`，全文随快照保留在 `类型声明/girs/LICENSE`。
  MIT 与 AGPL-3.0-or-later 兼容。
- 边界：快照只删除未引用文件、扁平化 `dist/` 并把一个 `.ts` 改名为 `.d.ts`，不改写声明
  内容；`global` 等 Shell 全局仅在 `类型声明/GJS环境.d.ts` 保留最小补充。升级方法与
  收录范围见 `类型声明/girs/说明.md`，由维护者手工执行。

## 4. 变更规则

新增第三方代码、二进制或生成资产时，必须在本文件登记其许可证，并确认与
AGPL-3.0-or-later 兼容；不兼容的依赖只能作为运行时的独立程序使用（如 xremap），
不进入本仓库。

## 5. Rust 编译依赖

二进制使用 anyhow、clap、libc、regex、reqwest（rustls）、serde / serde_json、sha2、
tempfile、zbus、zip 和 ctrlc。确切版本及传递依赖由 `Cargo.lock` 锁定，许可登记见
[06-Rust依赖许可证.tsv](06-Rust依赖许可证.tsv)（从该锁文件的 `cargo metadata` 生成）。
发布二进制包附带各依赖声明的许可文本，构建与分发均保留本项目 AGPL 许可。

原生归档使用 `tar`（MIT OR Apache-2.0）与 `flate2`（MIT OR Apache-2.0，Rust 压缩后端）。
它们及其间接依赖的原始许可与版权文件随二进制发行包的 `LICENSES/` 分发。
