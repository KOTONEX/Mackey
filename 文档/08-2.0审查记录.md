# 2.0.0 审查与验证

## 审查范围

中文命令接口与旧配置拒绝、生成器行为差分、GNOME 冲突迁移/备份/还原、
HOME/XDG 路径与软链边界、引擎下载/ZIP/ELF 架构校验、焦点来源与 IPC 协议、
systemd 参数转义与安装卸载、GJS 扩展契约、虚拟键盘 ABI 和进程清理、许可证与发行打包。

## 实现保障

- 自有命令、参数和清单字段使用中文，配置只接受当前接口，不自动转换旧字段。
- 虚拟键盘测试为注入器和引擎建立独立进程组，退出时终止并回收；焦点桥单独回收。
- 打包显式编译 rustc 宿主目标，从 Cargo 元信息读取产物目录，支持自定义构建目录。
- 工作流使用 Cargo 单一版本源、完整 Git 历史、stable 和统一原生检查；
  分支 CI 与标签构建覆盖 x86_64/aarch64。
- 发行包解压后实际执行二进制，验证版本、许可证、日志和嵌入清单生成的完整 JSON。
- 焦点桥通过 poll 等待监听 socket 的可读事件，连接到达立即唤醒；
  50 ms 超时用于检查退出标志。性能与方法见 [main 与 rust 对比](09-main与rust对比.md)。
- 正式发行限定为标签提交属于远程 `main` 历史，其余发布均标记为预发行且不设为 Latest。

## 验证与边界

统一检查包含格式、Clippy、Rust/GJS 类型、ShellCheck、JSON、115 条映射差分、
20 项 Rust 测试、隔离安装/卸载与旧配置拒绝/原文保留、13 项真实 GJS/D-Bus 契约断言。
发行包包含解压执行验证；工作流使用 actionlint 检查。

本机的虚拟键盘端到端用例未运行：已有用户 xremap 全局捕获键盘，测试设备可能被两个引擎同时捕获。
审查和测试没有停止该服务、安装到实际用户配置或修改实际 GNOME 快捷键。
CI 不伪造 `/dev/uinput` 验证结果；GitHub 的两种架构 runner 执行可隔离的完整离线检查与打包。

二进制使用 Ubuntu 24.04 runner 的系统 glibc，支持 x86_64/aarch64；不承诺兼容更老的 glibc。
Rust 仅固定 Edition 2024，不设 Rust 版本号约束。
