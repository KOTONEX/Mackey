# 2.0.0 审查记录

审查基线为 `rust` 分支的重写提交 `c0f9935`，后续修正与工作流改动单独提交。

## 范围

逐项检查中文命令接口与旧配置升级、生成器与旧版行为差分、GNOME 冲突迁移/备份/还原、
HOME/XDG 路径与软链边界、引擎下载/ZIP/ELF 架构校验、焦点来源与 IPC 协议、
systemd 参数转义与安装卸载、GJS 扩展契约、虚拟键盘 ABI 和进程清理、许可证与发行打包。

## 已修正问题

- 部分说明保留旧参数名与清单字段名，现统一为真实中文接口。
- 虚拟键盘测试的后台引擎可能存活至超时，现为注入器/引擎建立独立进程组，退出时终止并回收；焦点桥单独回收。
- 打包写死 `target/release`，可能忽略自定义 Cargo 构建目录或误选交叉目标。
  现显式编译 rustc 宿主目标，从 Cargo 元信息读取产物目录。
- 旧工作流仍引用已删除的 VERSION、Python/英文开发命令和打包脚本。
  现使用 Cargo 单一版本源、完整 Git 历史、stable 与统一原生检查；分支 CI 与标签发布都覆盖两种架构。
- 发行包增加解压验证：实际执行包中二进制、验证版本/许可证/日志，并用嵌入清单生成配置，与旧版基准比较。

## 验证与边界

本地统一检查通过：格式、Clippy、Rust/GJS 类型、ShellCheck、JSON、115 条旧版映射差分、
20 项 Rust 测试、隔离安装/卸载与旧英文配置原文备份、13 项真实 GJS/D-Bus 契约断言。
发行包解压验证通过；工作流使用 actionlint 检查。

本机的虚拟键盘端到端用例未运行：已有用户 xremap 全局捕获键盘，测试设备可能被两个引擎同时捕获。
审查和测试没有停止该服务、安装到实际用户配置或修改实际 GNOME 快捷键。
CI 不伪造 `/dev/uinput` 验证结果；发行前由 GitHub 的两种架构 runner 执行可隔离的完整离线检查与打包。

二进制使用 Ubuntu 24.04 runner 的系统 glibc，支持 x86_64/aarch64；不承诺兼容更老的 glibc。
Rust 仅固定 Edition 2024，不设 Rust 版本号约束。
